# Thinkbase Brand Reference

## Colors

### Primary
- **Brand Blue:** `#2563EB`
- **Brand Blue Hover:** `#1D4ED8`
- **Brand Blue Light:** `#3B82F6`
- **Brand Blue Soft:** `rgba(37, 99, 235, 0.08)`

### Text
- **Primary:** `#0A0B0D`
- **Secondary:** `#6B6B6B`
- **Tertiary:** `#9C9C9C`
- **Inverse:** `#FFFFFF`

### Background
- **White:** `#FFFFFF`
- **Surface:** `#F5F5F5`
- **Surface Light:** `#F9F9F9`

### Status
- **Success:** `#10B981`
- **Warning:** `#F59E0B`
- **Error:** `#EF4444`

### Border
- **Default:** `#E5E5E5`
- **Light:** `rgba(229, 229, 229, 0.60)`

## Typography

### Brand Font
- **Family:** Space Grotesk
- **Weight:** 700 (Bold)
- **Header size:** 20px, letter-spacing: -0.5px
- **Display size:** 28px, letter-spacing: -0.8px

### Body Font
- **Family:** System stack — `-apple-system, BlinkMacSystemFont, 'SF Pro Text', 'Segoe UI', Roboto, sans-serif`
- **Base size:** 14px
- **Weights:** 400 (regular), 500 (medium), 600 (semibold), 700 (bold)
